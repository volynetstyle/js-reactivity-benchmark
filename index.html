How To Read This

reflex-quant has the strongest relative profile in this run, 15.8% ahead of reflex by geometric mean. It takes 18 of 51 scenarios decisively, while reflex takes 1.

Each scenario was measured with all frameworks on one VM. The row interval is a 95% order-statistic interval for the median within one process: it covers sample noise only, not a new process, another VM or another CPU model. The leaderboard score has no interval of its own: it was measured on one VM per scenario, and different scenarios ran on different CPU models. A ≈ next to a time means its interval overlaps the leader's; such scenarios count as nobody's win. Capped rows use one cold sample and have no interval. All intervals describe repeat measurements of this run on GitHub-hosted runners, not the speed of a runtime on other hardware. Hover a row for its interval and noise.

Interpret wins through the scenario taxonomy: creation, update, pull/push propagation, dynamic dependency churn, large graphs, lifecycle pressure, and memory behavior can favor different runtimes.
