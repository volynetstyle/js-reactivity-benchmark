How To Read This

reflex-quant has the strongest relative profile in this run, 23.2% ahead of alien-signals by geometric mean. It takes 5 of 51 scenarios decisively, while alien-signals takes 1.

Each scenario was measured with all frameworks on one VM, on 3 independent VM sets, in 3 fresh processes per VM. The row score is the median of the per-machine estimates and its interval is their range; with 3 machines a range covers the cross-machine median with only ~75% probability, so it is not a 95% interval. The leaderboard score is computed separately for each of the 3 machine sets (ratios within one VM) and the median is shown with the range; a ≈ next to a rank means its range overlaps the one above. A ≈ next to a time means its interval overlaps the leader's; such scenarios count as nobody's win. Capped rows use one cold sample and have no interval. All intervals describe repeat measurements of this run on GitHub-hosted runners, not the speed of a runtime on other hardware. Hover a row for its interval and noise.

Interpret wins through the scenario taxonomy: creation, update, pull/push propagation, dynamic dependency churn, large graphs, lifecycle pressure, and memory behavior can favor different runtimes.

Not ranked: @reatom/core (11 failed: timeout, out-of-memory); dalien-signals (1 failed: stack-overflow); kairo 0.8 alpha (11 failed: timeout); Svelte v5 (9 failed: timeout). A failed row (wrong result, crash, out of memory, timeout) is a result; scoring such a library over only the scenarios it completed would rank it on an easier workload set. Its completed rows still appear in every per-test card.
